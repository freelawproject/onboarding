# Archive — superseded docs

**Status: superseded and unmaintained. Don't follow anything in this directory as current guidance.**

These are the topic-organized onboarding docs that came before the [day-one path](../day-one.md). They were written in February–March 2026 and are no longer reviewed for accuracy. Parts of them are known to be stale — dependency and stack details in particular have drifted.

**If you're getting set up, start at the [repo README](../README.md).**

## Why it's here and not deleted

The day-one path is deliberately short and covers the critical path only. This directory is raw material for the parts that earn their way back: when a real person needs one of these topics, we rewrite the piece they needed and put it back at the root, current and owned.

## Expiry

This directory is temporary. It gets deleted once the day-one path has been walked end to end by someone new and the content worth keeping has been rewritten. A public directory of superseded setup instructions is a hazard for readers who can't yet tell what's authoritative, so the default is deletion rather than indefinite storage.
