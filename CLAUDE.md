# Onboarding Docs

## Tone

These are onboarding docs for new teammates. Keep the tone **welcoming and positive**:

- Frame guidance as benefits and best practices, not warnings or put-downs
- Say what _to_ do, not what _not_ to do — lead with the positive pattern
- Avoid snark, sarcasm, or language that implies the reader would do the wrong thing
- "This helps because..." over "Don't do X because..."
- Direct is good; harsh is not

## Formatting

Run `prettier --write "**/*.md"` before committing — quoted so prettier expands the glob and recurses into subdirectories. No pre-commit hook — just run it manually.
