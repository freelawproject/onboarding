# Welcome to FLP

Free Law Project is a non-profit that provides free, public access to legal data. We build and maintain open-source tools that make the legal system more transparent and accessible.

This guide is your starting point as a new developer at FLP. It covers how we work, what tools we use, and where to find everything else.

## What This Guide Covers

- **Culture** - Values, communication norms, how decisions get made
- **Dev Environment** - Tooling setup for your machine
- **Git Setup** - SSH keys, gitconfig, global hooks
- **Git Workflow** - Branching, commits, PRs, sprint flow
- **Coding Standards** - Style, linting, testing philosophy
- **AI-Assisted Dev** - Claude Code setup and conventions
- **Projects** - Map of FLP repos and how they connect
- **Resources** - Links to HR, wikis, Slack, and external references

## What It Doesn't Cover

Project-specific setup lives in each repo (e.g., CourtListener has its own wiki and Docker instructions). HR policies live in the [HR repo](https://github.com/freelawproject/hr). This guide links to both but doesn't duplicate them.

## Suggested Reading Order

1. [Culture](culture.md) - Understand how we work before diving into tools
2. [Dev Environment](dev-environment.md) - Get your machine set up
3. [Git Setup](git-setup.md) - Configure SSH keys, gitconfig, and hooks
4. [Git Workflow](git-workflow.md) - Learn the PR and sprint process
5. [Coding Standards](coding-standards.md) - Code quality expectations
6. [AI-Assisted Dev](ai-assisted-dev.md) - Claude Code setup
7. [Projects](projects.md) - Find the repo you'll be working on
8. [Resources](resources.md) - Bookmark the important links

## First-Week Checklist

- [ ] Get added to the [FLP GitHub org](https://github.com/freelawproject)
- [ ] Join Slack and introduce yourself
- [ ] Set up your [dev environment](dev-environment.md)
- [ ] Configure [git](git-setup.md) (SSH keys, FLP email, global hooks)
- [ ] Install and configure [Claude Code](ai-assisted-dev.md)
- [ ] Read the [culture](culture.md) and [coding standards](coding-standards.md) pages
- [ ] Clone the repo(s) you'll be working on (see [Projects](projects.md))
- [ ] Review the [HR handbook](https://github.com/freelawproject/hr) for policies and benefits
